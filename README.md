# 我的工作台

一个单文件的个人工作台网页，面向高校教师的日常事务管理。所有 CSS / JS / 图标 / 图表全部内联在 `index.html` 里，**零外部依赖**，离线也能打开使用。

## 版面：左中右三栏

- **左栏**：四个功能页签（今天要处理 / 时间轴 / 全部任务 / 统计），点击切换中间内容，不用上下滚动找模块。
- **中间**：当前页签的具体内容。
- **右栏**：录入区——上半是「添加待办」（打字或语音，自动归类），下半是「补记已经做过的」（刚才 30 分钟 / 1 小时 / 自己挑时间，直接跳到时间轴补一段），最下面是今日小结。

手机上自动变成「底部页签 + 右下悬浮加号 + 从底部上滑的录入抽屉」，单手也能录。

## 四个模块

1. **今天要处理** —— 置顶的待办区。逾期项标红，每条可一键顺延；当天没做完的任务会在第二天自动滚到今天。录入在右栏，写一句自动分流到「教学 / 科研 / 行政 / 家庭生活」。
2. **时间轴（补记）** —— 苹果日历式的日视图。**在空白处按住往下拖**就能圈出一段时间，松手后写一句「这段时间干了什么」，自动归类并存档；色块可以整体拖动、拖底边改结束时间、点一下改内容或删除。顶部有一条**结构占比条**，一眼看出这一天是教学多、科研多还是生活多；生活里的家务 / 运动 / 陪伴 / 自我提升 / 健康 / 闲适还会单独统计。
3. **全部任务** —— 按分类和状态筛选。每条任务可以「开始 / 结束」计时，结束后时间**累加到该任务**上（结束 ≠ 完成，下次可以接着计时继续累计），也可以标记完成或删除。
4. **统计** —— 关键指标卡片、分类分布、近 7 天用时柱状图、**任务甘特图**。全部用内联 SVG 手绘，不依赖任何图表库。

## 分类设计：两层，但只有一层颜色

- **一级（决定颜色，4 种）**：教学 = 紫 `#A79BE0` / 科研 = 红 `#E18B84` / 行政 = 蓝 `#7FA8DC` / 家庭生活 = 绿 `#7FC4A4`
- **二级（不新增颜色，只在色块里以小字显示）**：生活下面再分 通勤 / 家务 / 运动 / 陪伴 / 自我提升 / 健康 / 闲适

这样「收拾书房 → 家庭生活 · 家务」「晨间运动 → 家庭生活 · 运动」「通勤路上 → 家庭生活 · 通勤」颜色同族但能一眼分开，色块也不会花。

**通勤**没做成第五个大类：它既不是教学科研，也不是行政事务，算进「行政」会把行政时长撑大、看不出真实工作量。放在生活下当二级，既能在时间轴上看见，又能在「生活里面」那行单独统计。

## 数据存储

页面有两种运行模式，会自动判断：

- **在线模式**：运行在 WorkBuddy「资料库」环境中时，读取 `window.__SMART_PAGE__.database` 接口，数据存在云端数据表里，多设备自动同步。
- **本机模式**：在没有该接口的环境（例如本仓库部署到帽子云后）中打开，数据存在浏览器 `localStorage` 里，**只保存在当前这台设备、当前这个浏览器中**，不会跨设备同步。

无论哪种模式，功能都完整可用。数据迁移靠抽屉里的 **「导出 JSON 备份」** 和 **「导入恢复」** 两个按钮。

> 换设备或换浏览器时，先在原设备导出 JSON，再到新设备导入即可。

## 使用建议

- 手机上用浏览器打开后，通过「分享 → 添加到主屏幕」可以当成 App 使用。
- 首次打开会自带 5 条示例数据（含 1 条逾期）方便看效果，看完可以在抽屉里点「清空示例数据」。
- 数据积累多了以后建议定期导出 JSON 做一份本地备份。

## 部署

纯静态站点。仓库根目录的 `index.html` 就是入口，无需构建步骤。

在帽子云创建应用时，选择本仓库与 `main` 分支，构建配置留空即可；如果自动识别不出，把「构建命令」留空、「发布目录」填 `.`。
